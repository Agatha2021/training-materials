本仓库提供「问题解决型课程开发」流程配套的 4 个 AI Skill 包，供内训师下载使用。
所有文件免登录下载，无需注册 GitHub 账号。

按课程开发流程的顺序排列：
| 步骤 | Skill 包 | 作用 |
|---|---|---|
| 1 | `skill-kechengzhutixuanze.zip` | 课程主题选择：从工作任务和上级要求中聚焦出值得开发的课题 |
| 2 | `skill-luoliezhishiqingdan.zip` | 罗列知识清单：围绕主题拆解知识点，形成知识结构 |
